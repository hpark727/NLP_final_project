# Revealing Distribution-Locality in Safety Fine-Tuning via Adaptive Prefix Mining

**Hael Park, Ethan Cheng, Andrew Wang** — Princeton University (COS 484, 2026)

> Static harmful-prefix SFT substantially reduces prefilling attack success rates, but this robustness is *distribution-local*: models fine-tuned against static prefixes remain vulnerable to semantically similar adaptive prefixes generated by the model itself. ASR rises from 15.2% at k=5 to 53.0% at k=40 on Qwen3, despite <1% static ASR.

---

## Overview

Prefilling attacks jailbreak LLM safety guardrails by forcing a model to begin its response with a compliant prefix. [Qi et al. (2024)](https://arxiv.org/abs/2406.05946) propose **harmful-prefix SFT** (delayed-refusal augmentation) to defend against this. We reproduce their results on **Llama-3.2-3B** and **Qwen3-4B-Instruct-2507**, then probe how far that robustness generalizes via **adaptive prefix mining**: a gradient-free procedure that generates adversarial prefixes by prompting the target model itself.

Key findings:
1. Static-prefix SFT reproduces Qi et al. — ASR drops from 93–96% (Llama base) to under 12%.
2. Adaptive prefixes break that robustness: Qwen3 augmented model reaches 33–53% adaptive ASR despite ≤0.6% static ASR.
3. Cross-model transfer is unidirectional: Llama-mined prefixes transfer strongly to Qwen3, but not vice versa.
4. 50/50 mixed SFT (static + adaptive) collapses static robustness without closing the adaptive gap.

## Pipeline

### 1. Static-Prefix SFT (reproducing Qi et al.)

Fine-tune with delayed-refusal augmentation on the Llama-2 safety dataset:

```bash
python training/finetune_tinker.py \
    --model_name meta-llama/Llama-3.2-3B \
    --sft_type static \
    --output_name Llama-3.2-3B-Augmented
```

Or use the shell script:
```bash
bash scripts/finetune_qwen_llama2_safety_augmented.sh
```

Training hyperparameters: LoRA rank 32, lr 1e-4, 3 epochs, α=0.2 safety weight, 256 safety examples + 20k anchor examples.

### 2. Evaluate Static ASR

```bash
# k ∈ {5, 10, 20, 40}
python evaluation/eval_safety_tinker.py \
    --model_path <tinker_ckpt_or_hf_id> \
    --prefix_type static \
    --k 10 \
    --save_path logs/prefilling/llama_augmented_static_k10.json
```

### 3. Adaptive Prefix Mining

Mine adaptive prefixes against an augmented model:

```bash
python mining/mine_adaptive_prefixes_tinker.py \
    --model_path <augmented_model_ckpt> \
    --harmful_data finetuning_buckets/datasets/data/safety_bench/Harmful-HEx-PHI.jsonl \
    --seed_lengths 10 20 \
    --n_samples 3 \
    --save_path logs/adaptive_prefixes/mined_augmented_tinker_bos_clean.jsonl
```

Then evaluate the augmented model against its own mined prefixes:

```bash
python evaluation/eval_safety_tinker.py \
    --model_path <augmented_model_ckpt> \
    --prefix_type adaptive \
    --prefix_file logs/adaptive_prefixes/mined_augmented_tinker_bos_clean.jsonl \
    --k 10 \
    --save_path logs/adaptive_prefixes/eval_augmented_on_gen2_v2_bos_clean_k10.json
```

Or run the full sweep:
```bash
bash scripts/mine_and_eval_qwen_augmented_adaptive.sh
```

### 4. 50/50 Mixed SFT

Prepare the mixed dataset and fine-tune:

```bash
python mining/prepare_adaptive_recovery_data.py \
    --static_data finetuning_buckets/datasets/data/tasks/data_augmentation/llama2_safety_data_direct.jsonl \
    --adaptive_prefixes logs/adaptive_prefixes/mined_augmented_tinker_bos_clean.jsonl \
    --output logs/adaptive_recovery/mixed_50_50_train.jsonl

python training/finetune_tinker.py \
    --model_name meta-llama/Llama-3.2-3B \
    --sft_type mixed_50_50 \
    --train_data logs/adaptive_recovery/mixed_50_50_train.jsonl \
    --output_name Llama-3.2-3B-Mixed-50-50
```

### 5. Cross-Model Transfer Evaluation

```bash
bash scripts/run_cross_adaptive_qwen4b_llama3b.sh
```

### 6. Mechanism Analysis (Appendix A.2)

Logit trajectory and refusal direction analysis:

```bash
# Compute per-step refusal log-probabilities
python analysis/compute_logit_trajectory.py \
    --model_path <augmented_model_ckpt> \
    --static_prefixes logs/adaptive_prefixes/... \
    --adaptive_prefixes logs/adaptive_prefixes/mined_augmented_tinker_bos_clean.jsonl \
    --save_path logs/adaptive_prefixes/logit_traj/logit_trajectory.csv

# Generate paper figures
python plots/plot_logit_trajectory.py
python plots/plot_adaptive_prefix_sweep.py
```

## Results

**Table 1: Static-prefix ASR (%) — HEx-PHI, n=330**

| Model | k=5 | k=10 | k=20 | k=40 |
|---|---|---|---|---|
| Llama-3.2 (base) | 95.8 | 93.3 | 95.2 | 93.0 |
| Llama-3.2 (augmented) | **6.7** | **7.6** | **9.4** | **11.8** |
| Qwen3 (base) | 49.7 | 63.0 | 65.2 | 62.4 |
| Qwen3 (augmented) | **0.3** | **0.6** | **0.6** | **0.3** |

**Table 2: Adaptive-prefix ASR (%) — self-mined prefixes**

| Model | k=5 | k=10 | k=20 | k=40 |
|---|---|---|---|---|
| Llama-3.2 (augmented) | 15.2 | 21.5 | 28.3 | 31.9 |
| Qwen3 (augmented) | 33.3 | 40.9 | 48.9 | **53.0** |
