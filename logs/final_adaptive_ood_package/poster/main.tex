\begin{alertblock}{Summary}
\begin{itemize}
    \item We present a neural network that learns to use episodic memory for event prediction. 
    \item The learned memory-retrieval policy shows a speed-accuracy trade-off that is sensitive to the cost of incorrect predictions. 
    \item Models that selectively encode at event boundaries had fewer retrieval errors. 
    \item Collectively, this model provides insights about why, in real data, episodic retrieval seems to be sensitive to prediction demand and uncertainty [1] and why episodic encoding seems to happen selectively at event boundaries [3, 4]. 
\end{itemize}


\end{alertblock}

\begin{block}{Model detail}


\begin{figure}
    \centering
    \includegraphics[width=.9\textwidth]{plots/model.png}
    \captionsetup{labelformat=simple}
    \caption{
    A) The model architecture; 
    B) Memories are a set of laterally competing evidence accumulators. 
    % The input weights (red) and the level of competition (blue) is controlled by the neural network. 
    \label{fig:model}
    \vspace{-5mm}
    }
\end{figure}

\textbf{Cortex} is a recurrent neural network (LSTM) that predicts the upcoming state. 

\textbf{Hippocampus} represents memories as a set of evidence accumulators. Each memory is a previously saved cortical pattern. 
\begin{itemize}
    \item \textbf{Retrieval} is an evidence-accumulation process that determines which memory to retrieve. Evidence is proportional to the similarity between the current state and stored memory. 
    \item The \textbf{retrieval control} layer controls the feed-forward weights and the level of lateral competition between different memories.
    \item \textbf{Encoding} a new memory corresponds to adding a new accumulator. 
\end{itemize}

The model is trained with reinforcement learning. The reward is positive/negative if the prediction is correct/incorrect. The model can say ``don't know'', in which case the reward is zero.

\begin{block}{A context-dependent event prediction task}

An \textbf{event sequence} is a sample path from a event schema conditioned on a situation (fig \ref{fig:task}). An \textbf{event schema} is a graph, where each transition is controlled by a particular feature of the situation (\ref{fig:task} A). Thus, knowing the features of the situation is useful for event prediction.

\begin{block}{Use episodic memory to predict upcoming events}

There are three conditions (inspired by [1]): during test, the ongoing situation is ... 
\begin{itemize}
    \item recently observed (RM; recent memory)
    \item observed in distant past (DM; distant memory)
    \item new (NM; no memory)
\end{itemize}

In the DM condition, relevant information is not in working memory, so it needs to be recalled from episodic memory. DM prediction accuracy starts low, and increases after episodic recall takes place.

\begin{block}{Properties of the learned recall policy}

Recall is sensitive to whether information is already in working memory (fig \ref{fig:mem-act}: lower recall in RM condition than DM; see also fig \ref{fig:uncertainty}). We also manipulated the penalty associated with incorrect predictions. 
When penalty is high, recall is delayed (fig \ref{fig:mem-act} A vs. B) and false recall is low (fig \ref{fig:roc}), similar to a well-established model of hippocampus [2].

\begin{block}{Encoding at event boundaries reduces subsequent memory errors}

We found models that 
\textbf{\textcolor{cbblue}{encode at event boundaries}} 
performed better at subsequent recall (fig \ref{fig:enc-compare}), compared to models that also encode episodic memories within an event sequence (i.e. 
\textbf{\textcolor{cbbrown}{cumulative encoding}}), 
because encoding within an event sequence leads to more confusable memories (fig \ref{fig:enc_demo}). 


\begin{figure}
    \centering
    \includegraphics[width=1\linewidth]{plots/enc-acc-horizontal.png}
    \captionsetup{labelformat=simple}
    \caption{
    Event prediction accuracy for models that 
    \textcolor{cbblue}{encode at event boundaries }; vs. models that also
    \textcolor{cbbrown}{
    encode within an event sequence}. 
    }
    \label{fig:enc-compare}
\end{figure}

    \label{fig:enc_demo}
\end{figure}
